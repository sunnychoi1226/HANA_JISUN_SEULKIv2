# 인센티브 호텔 추천·견적 시스템 v27

## V27 핵심 변경

V27은 검색 속도와 검증 데이터 재사용을 우선한 버전입니다.

- 주요도시 39개 중심 좌표를 프론트 코드에 내장하여 도시 입력 시 외부 API/Supabase를 기다리지 않고 지도를 먼저 표시
- Supabase `hotels` 내부 Master와 `hotel_discovery_cache` 검증 캐시를 분리해 사용
- 30일 이내 저장 캐시가 있으면 실시간 Overpass 검색을 실행하지 않음
- 완전 신규 도시이면서 저장 캐시가 없을 때만 Nominatim/Overpass 사용
- 외부 신규 검색은 화면을 장시간 붙잡지 않도록 약 10초 이내에서 종료
- 검색 단계 문구를 화면에 표시해 내부 Master / 검증 캐시 / 신규 외부 검색 중 어디까지 진행되었는지 확인 가능
- Supabase 검증 캐시의 `total_rooms`, `largest_event_capacity`, `meeting_rooms`, `tags`, `verification_status`, `source_urls` 등을 추천과 화면에 반영
- 기존 내부 Master 호텔과 검증 캐시가 같은 호텔이면 내부 요금/메모는 유지하고 검증된 객실수·연회장·공식정보를 보강
- 검색 버튼은 성공/실패 여부와 관계없이 정상 상태로 복귀

## 현재 검증 캐시

괌은 실제 검증 캐시를 먼저 구축했습니다.

- 저장 후보: 20개
- 객실 수: 20개 입력
- 연회/이벤트 공간: 19개 확인
- 최대 수용인원: 18개 입력
- 태그: 20개 입력
- 공식 사이트 및 Guam Visitors Bureau 등 확인 가능한 공개 출처 기반
- 확인되지 않는 정보는 임의 생성하지 않고 `부분 검증` 또는 `확인 필요`로 유지

괌 검색 시 저장 캐시가 유효하면 Overpass 실시간 검색을 하지 않습니다.

## 검색 순서

주요도시:
1. 도시 입력
2. 중심 지도 즉시 표시
3. `hotels` 내부 Master 조회
4. `hotel_discovery_cache` 30일 캐시 조회
5. 캐시가 있으면 즉시 추천 및 마커 표시
6. 실시간 외부 검색 없음

완전 신규 도시:
1. 저장된 도시 좌표 확인
2. 없으면 Nominatim으로 좌표 확인
3. 지도 표시
4. 내부 Master/검증 캐시 확인
5. 캐시가 없을 때만 Overpass 신규 검색
6. 최대 30개 저장하여 다음 검색부터 캐시 사용

## 배포

GitHub 저장소 루트에 다음 파일/폴더가 바로 보여야 합니다.

- `public/`
- `netlify/`
- `netlify.toml`
- `README.md`

Netlify 환경변수:
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`

AI 공식정보 검증/메일 분석 기능을 사용할 경우 추가:
- `OPENAI_API_KEY`

## 배포 확인

사이트 상단에 아래 문구가 보여야 V27이 실제 배포된 것입니다.

`배포 버전 V27 · 주요도시 즉시지도 · 검증캐시 우선 · 신규도시만 외부검색`

괌 테스트 시 정상 흐름:
1. `남태평양` 선택
2. 도시 `괌` 입력
3. 중심 지도가 먼저 표시
4. `호텔 추천 보기`
5. 화면에 내부 Master → 검증 캐시 확인 단계 표시
6. 저장 캐시를 사용해 결과와 마커 표시
7. `실시간 외부검색 없음` 문구 확인

## 데이터 원칙

- 내부 Master는 과거 이력/요금/담당자/사내 메모 보강용
- 외부 검증 캐시는 실제 호텔 후보와 공개 검증 정보용
- 확인되지 않은 객실수·연회장·버스 접근·요금은 임의 생성하지 않음
- 공개요금은 실제 일정 기준 그룹 요금이 아니므로 최종 RFQ 확인 필요
