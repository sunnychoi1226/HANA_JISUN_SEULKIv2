# 호텔 견적 통합솔루션 v30

## V30 방향

실제 사용자에게 공유했을 때 개발·테스트·배포 과정이 화면에 드러나지 않도록 사용자 화면 문구를 전면 정리한 버전입니다.

### 주요 변경
- 메인 제목을 `호텔 견적 통합솔루션`으로 변경
- 화면 내 버전 번호 및 배포 상태 문구 제거
- 개발·테스트용 사번 안내 문구 제거
- `Supabase`, `캐시`, `외부검색`, `OSM`, `DB` 등 개발 용어를 사용자 화면에서 제거 또는 업무 용어로 변경
- 불필요한 소개 문구 대신 접을 수 있는 `사용 매뉴얼` 추가
- 추천/견적 화면 안내 문구를 실제 업무 흐름 중심으로 단순화
- 로그인 화면은 `임직원 전용 시스템 / 사번 입력`만 노출
- 기존 기능, 지도, Supabase 연결, 검증 데이터, 추천 로직은 유지

### 사용자에게 보이는 핵심 안내
- 호텔 추천부터 견적 요청, 회신 정리, 비교까지 한 화면에서 관리
- 추천 정보는 참고용이며 실제 요금·객실 가능 여부·행사 조건은 호텔에 최종 확인 필요
- 호텔 회신 원문은 저장하지 않고 분석된 견적 정보만 저장

## 배포
GitHub 저장소의 기존 앱 파일을 V30 파일로 교체한 뒤 Commit하면 됩니다.
Netlify가 GitHub와 연결되어 있다면 자동 재배포됩니다.

Supabase 추가 작업은 필요하지 않습니다.
