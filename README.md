# 인센티브 호텔 추천·견적 시스템 v29

## V29 수정
V28의 `money is not defined` 오류를 수정했습니다.

원인: 예산, 참고요금, 견적비교에 사용되는 공통 `money()` 함수가 빠져 있었습니다.

V29에서는 `money()` 함수를 복구했고, V28의 주요도시 즉시지도/검증캐시 우선/Supabase Secret key 수정도 그대로 유지합니다.

## 배포 확인
사이트 상단에 아래 문구가 보여야 합니다.

`배포 버전 V29 · money 오류 수정 · 지도 즉시이동 · 검증캐시 우선`

## 괌 테스트
1. 남태평양 선택
2. 괌 입력
3. 중심지도 즉시 이동 확인
4. 호텔 추천 보기
5. 내부 Master → 검증캐시 조회
6. 저장 캐시 사용 및 `실시간 외부검색 없음` 확인
