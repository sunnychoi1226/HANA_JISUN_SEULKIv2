# 호텔 견적 통합솔루션 v32

## V32 점수 기준

추천 점수는 100점 기준이며, 실제 호텔 선정에서 가장 중요한 세 가지 조건에 90점을 배정합니다.

### 핵심 3개 항목 · 90점

- 가격 적합도: 35점
  - 목표 예산에 가까울수록 높은 점수
  - 허용 예산을 초과할수록 빠르게 감점
  - 가격이 아직 확인되지 않은 호텔은 중간 수준의 임시 점수를 부여하고 실제 견적 확인 필요로 표시

- 객실 수용 가능성: 30점
  - 요청 객실 수를 실제로 수용할 수 있는지와 적정 여유를 평가
  - 총 객실수가 요청 객실의 3배 이상이면 만점
  - 그 이상 큰 호텔은 추가 가점하지 않음
  - 예: 30실 요청 시 90실 이상이면 객실 규모 항목은 만점

- 연회장 수용 가능성: 25점
  - 필요한 행사 인원을 수용할 수 있는지 평가
  - 필요 인원의 2배 이상 수용 가능하면 만점
  - 그 이상 큰 연회장은 추가 가점하지 않음

### 보조 항목 · 10점

- 호텔 등급: 3점
- 대형버스 접근: 2점
- 행사 유형 적합도: 3점
- 검증·내부 이력: 2점

## 점수 해석

점수는 '호텔이 크면 무조건 높은 점수'가 아니라,
`가격이 맞는가 → 객실을 충분히 확보할 수 있는가 → 필요한 연회장을 수용하는가`
순으로 실무 적합도를 비교하기 위한 기준입니다.
