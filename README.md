# 호텔 견적 통합솔루션 v33

## V33 반영 내용

### 화면/문구
- 최초 접속 화면 제목: `호텔 견적 통합솔루션`
- 사번 입력 placeholder: `사번`
- 메인 좌측 상단에 하나투어 로고와 `호텔 견적 통합솔루션`을 한 줄로 배치
- 추천 주의문을 상단 헤더에서 제거하고 `추천 결과` 영역 아래로 이동
- 검색 조건 안내 문구를 검색 버튼 하단으로 이동
- 연회장 필요 수용 인원을 예산 입력 영역 아래로 이동
- 연회장 필요 / 대형버스 접근 / 적합도 50점 미만 숨기기 / 해변·리조트형 선호를 한 영역에 배치
- 예산 허용 범위 초과 호텔의 결과 포함 여부 체크박스 추가

### 지역
- 호놀룰루와 마우이를 `미주`로 변경
- Supabase cities 데이터도 `미주`로 반영

### 견적 비교
- Supabase `quotes`, `quote_history` 테이블 사용
- 5초 자동 동기화 제거
- 견적 비교 탭을 열 때 1회 조회
- 저장/수정/삭제 직후 즉시 갱신
- `최신 데이터 새로고침` 버튼 제공

### 호텔 회신 자동 추출
- OpenAI API 호출 제거
- 외부 유료 AI API를 사용하지 않는 브라우저 규칙 기반 자동 파서로 변경
- 메일 붙여넣기 후 객실 수/요금, 통화, 박수, 인원, Resort Fee, Tax, Commission, Option Date, 조식 포함, FOC/Rebate/Upgrade/Seminar/F&B 조건 등을 자동 추출
- 확정 답변과 요청 문장이 혼재된 경우 `확인 필요` 표시
- 자동 추출 근거 문장을 화면에서 확인 가능
- 원문 메일은 DB에 저장하지 않음

### 점수
V32의 100점 기준을 유지합니다.
- 가격 35
- 객실 수용 30
- 연회장 수용 25
- 등급 3
- 버스 2
- 행사유형 3
- 검증/이력 2
